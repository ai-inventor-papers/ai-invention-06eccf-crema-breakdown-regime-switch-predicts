# Reproducibility Instructions

## 1. Getting This Artifact

This workspace is published as one folder of a public GitHub repository. Clone the repository and navigate to the evaluation folder:

```bash
git clone <repo-url>
cd <repo-dir>/round-1/evaluation-1/src
```

## 2. Environment Setup

### System Requirements
- **OS**: Ubuntu 20.04+ or macOS 12+ (Apple Silicon)
- **Python**: 3.12
- **Hardware**: CPU-only, 2+ vCPUs, 4+ GB RAM (no GPU needed)

### Create Virtual Environment

```bash
uv venv .venv --python=3.12
source .venv/bin/activate
uv pip install -e .
```

This installs all dependencies pinned to exact versions (see `pyproject.toml`):
- numpy==2.5.5, scipy==1.18.1, pandas==3.1.1
- matplotlib==3.11.2, loguru==0.8.0
- psutil==7.2.2, jsonschema==4.26.0

## 3. Data and Inputs

**No external data downloads or API keys are needed.** All data is generated from scratch by the included scripts:

- `full_data_out.json` — synthetic coffee cooling dataset panel (3 datasets, 44 rows) generated by `generate_dataset.py`
- `method_out.json` — experiment fit table (5 candidates × 3 datasets) generated by `generate_method.py`

These files are included in the repository. If you need to regenerate them:

```bash
python generate_dataset.py
python generate_method.py
```

## 4. Exact Commands Run

### Step 1: Generate dataset panel
```bash
python generate_dataset.py
# Output: full_data_out.json (25KB), mini_data_out.json, preview_data_out.json
# Runtime: <1 second
```

### Step 2: Run experiment fits
```bash
python generate_method.py
# Output: method_out.json (19KB), mini_method_out.json, preview_method_out.json
# Runtime: ~30 seconds (curve fitting on 3 small datasets)
```

### Step 3: Run evaluation
```bash
python eval.py
# Output: eval_out.json (21KB), fig1_heldout_rmse.pdf, fig2_c3_tau_sweep.pdf
# Runtime: ~2 minutes (includes 5000-draw bootstrap)
```

### Step 4: Independent re-derivation
```bash
python rederive.py
# Verifies headline numbers from raw data
# Runtime: <5 seconds
```

## 5. Expected Output

After running `eval.py`, you should get:

**eval_out.json** containing:
- `metrics_agg`: aggregate metrics (mean heldout RMSE per candidate, mean delta-BIC, etc.)
- `datasets`: per-dataset evaluation details
- `metadata`: survival rule results, bootstrap CIs, C3 ablation table, power note

**Key numbers to verify:**
- No survivors (empty `survivors` list)
- Closest candidate: C1 (coupled temperature-mass ODE)
- C3 mean heldout RMSE: 0.275°C (best but negative delta-BIC)
- C1 mean heldout RMSE: 1.819°C
- B0 (Newton) mean heldout RMSE: 1.310°C
- Bootstrap CI width on RMSE diff: ~3.5°C
- Minimum detectable effect at 95% power: ~2.5°C

**Figures:**
- `fig1_heldout_rmse.pdf` — grouped bar chart of heldout OOS RMSE
- `fig2_c3_tau_sweep.pdf` — C3 in-sample RMSE vs tau sweep

## 6. Hardware Used

- **CPU**: Apple Silicon (M-series), 2 vCPUs shared
- **RAM**: 16 GB (container limit)
- **GPU**: None (CPU-only computation)
- **Total runtime**: <5 minutes for all steps

## 7. Seeds

- Dataset generation: `np.random.default_rng(42)`, `np.random.default_rng(123)`, `np.random.default_rng(777)` (per dataset)
- Bootstrap: `np.random.default_rng(42)` (fixed seed)
- All results are fully deterministic given the same inputs
