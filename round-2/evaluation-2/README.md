## Full Summary

Evaluates a parsimonious crema-breakdown switching model with fixed tau (5.5 min) on four published coffee cooling datasets (Kurzweg 1988, Manitoba workshop, Ferreira 2024 cup, Lomen & Lovelock). Compares against Newton baseline (B0), piecewise two-exponential (B1), coupled mass-energy ODE (C1), Bayesian change-point (C2), and flux-crossover (C3) using out-of-sample RMSE, BIC, and drinkable-temperature (50°C) crossing error with 5000-draw paired bootstrap CIs. Key findings: C2 (Bayesian changepoint) achieves lowest OOS RMSE (1.66°C) and best crossing error (0.54 min); B1 has best BIC (-15.5); C3 (tau=5.5 fixed) RMSE=2.63°C, BIC=-15.2. All non-Newton models except C1 significantly outperform Newton on RMSE (bootstrap CIs exclude 0). Newton trajectory error peaks at 30 min (6.0°C, CI [4.6, 7.4]), confirming systematic deviation from single-exponential cooling. Results generated via eval.py with schema-validated exp_eval_sol_out output, 5 publication-ready figures via aii-data-fig-gen, and independent re-derivation script confirming all headline numbers.
